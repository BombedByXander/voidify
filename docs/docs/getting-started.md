Open Spotify desktop once, then run the installer as your regular user. Choose **Yes** when prompted to enable Voidify Marketplace.

## Windows

```powershell
iwr -useb https://raw.githubusercontent.com/BombedByXander/voidify/main/cli/install.ps1 | iex
```

## Linux and macOS

```sh
curl -fsSL https://raw.githubusercontent.com/BombedByXander/voidify/main/cli/install.sh | sh
```

## Commands

```sh
voidify -h
voidify update
voidify apply
```
