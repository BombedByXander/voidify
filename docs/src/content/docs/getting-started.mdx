Open Spotify desktop once, then run the installer as your regular user.

## Windows

```powershell
iwr -useb https://raw.githubusercontent.com/BombedByXander/voidify/main/cli/install.ps1 | iex
```

Open **Voidify** from Start. Setup uses the Spotify website edition to create a private Windows player with Marketplace. Rerun setup after a Spotify update.

## Linux and macOS

```sh
curl -fsSL https://raw.githubusercontent.com/BombedByXander/voidify/main/cli/install.sh | sh
```

## macOS and Linux commands

```sh
voidify -h
voidify update
voidify apply
```
