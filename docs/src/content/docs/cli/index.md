Voidify is primarily a command-line tool. This section covers the command reference.

## Quick Start

After [installing Spicetify](/docs/getting-started), the basic workflow is:

```bash
# Generate config (first run only)
spicetify

# Backup Spotify and apply Spicetify
voidify backup apply

# After making changes, apply them
voidify apply
```

## Getting Help

For help on any command:

```bash
voidify --help
voidify --help <command>
```

Example:

```bash
voidify --help config
```
